🤖 IBM Bob v2.0.3 — Agent Mode

Bob's Agent mode wrote every file via write_file + apply_diff, debugged Code Engine port binding in-task, and used the watsonx Orchestrate MCP to call import_tool + create_or_update_agent without leaving VS Code. 56 tasks · 100% Agent mode · ~12 hrs saved.

⚙️ IBM Code Engine

Serverless containerised Flask backend. Exposes the OpenAPI 3.0 /api/disruption endpoint consumed as a watsonx Orchestrate skill. Includes criticality scoring, EPA compliance alerts, and historical pattern analysis.

🎼 watsonx Orchestrate

Native agent that parses disruption intent, calls runDisruptionResponse, and returns a structured, decision-ready response — including stockout countdown and AI risk narrative from IBM Granite.
